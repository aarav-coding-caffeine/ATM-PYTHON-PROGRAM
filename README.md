# ATM Management System

## Introduction

This is a simple **ATM Management System** made using Python.

The program allows the user to perform basic ATM operations such as:

* Check balance
* Withdraw money
* Deposit money
* Check transaction history
* Exit the ATM

## Features

### 1. Check Balance

The user can check the current balance in the bank account.

### 2. Withdraw Money

The user can withdraw money from the account.

* The user must enter the correct PIN.
* The amount must be greater than 0.
* The account must have enough balance.

### 3. Deposit Money

The user can deposit money into the account.

* The amount must be greater than 0.
* The balance is updated after the deposit.

### 4. Transaction History

The user can see all deposits and withdrawals made during the program.

### 5. Exit

The user can exit the ATM program by selecting option 5.

## How to Run

1. Install Python on your computer.
2. Save the code in a file, for example:
   `atm.py`
3. Open the terminal or command prompt.
4. Run the program using:

```bash
python atm.py
```

5. The ATM menu will be displayed.
6. Enter the number of the operation you want to perform.
